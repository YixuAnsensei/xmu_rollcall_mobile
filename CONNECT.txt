v1.1.0 变更（开发中, 待新 APK 构建后更新链接）:
- CAS 自动登录: 内嵌 WebView + 本地原生模块读取 HttpOnly Cookie（对齐桌面版）
- 移除手动粘贴 Cookie 入口与 expo-web-browser
- 每次启动需重新登录（学校 Cookie 时效很短, 不做持久化）
- 新增 DEV_GUIDE.md 开发说明与使用指导

v1.0.0 变更:
- 升级到 Expo SDK 57 (RN 0.86.3 / React 19.2.3), 移除 @react-navigation
- 登录为手动粘贴 Cookie, /api/profile 验证并显示用户名
- android/ 原生工程由 expo prebuild 生成, 不再入库

开发调试（Expo Go）:
1. 手机和电脑连同一个 WiFi
2. 启动: bunx expo start --tunnel  (推荐, 免防火墙配置)
   或局域网模式需管理员放行:
   netsh advfirewall firewall add rule name="Expo DevServer 8082" protocol=TCP dir=in localport=8082 action=allow
3. Expo Go 扫终端二维码或输入 exp:// 地址
注意: CAS 登录依赖本地原生模块, Expo Go 无法测试, 需 EAS 构建 APK 真机验证
